# Валидатор конфигурационных файлов (INI)

Этот скрипт на Python проверяет локальный INI-файл на соответствие заданной структуре: наличие обязательных секций (`database`, `logging`) и обязательных ключей внутри них, а также базовую корректность типов (например, `port` должен быть числом).

## Требования

*   Python 3.6 или выше.
*   Стандартная библиотека Python (нет внешних зависимостей).

## Установка

Не требуется установка внешних пакетов, так как используется только `configparser` из стандартной библиотеки.

## Использование

1.  Создайте тестовый конфигурационный файл (например, `config.ini`).
2.  Запустите скрипт, передав ему путь к файлу:

    ```bash
    python validator.py config.ini
    ```

## Пример использования (Успешный)

**config.ini:**
```ini
[database]
host = localhost
port = 5432
user = admin
[logging]
level = INFO
```

**Вывод:**
```
--- Отчет валидации для config.ini ---
[УСПЕХ] Все обязательные секции присутствуют.
[УСПЕХ] Все обязательные ключи в секции [database] присутствуют.
[УСПЕХ] Тип 'port' в [database] корректен (число > 0).
[УСПЕХ] Все обязательные ключи в секции [logging] присутствуют.
----------------------------------
✅ Конфигурационный файл прошел валидацию.
```

## Пример использования (Неуспешный - отсутствует ключ)

**config_bad.ini:**
```ini
[database]
host = localhost
port = 5432
[logging]
level = INFO
```

**Вывод:**
```
--- Отчет валидации для config_bad.ini ---
[УСПЕХ] Все обязательные секции присутствуют.
[ОШИБКА] В секции [database] отсутствуют ключи: user
[УСПЕХ] Все обязательные ключи в секции [logging] присутствуют.
----------------------------------
❌ Конфигурационный файл НЕ прошел валидацию. Исправьте ошибки выше.
```
